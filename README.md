# Company Maker

Turn a rough idea into a **Company Brief**, a practical **roadmap**, and a **co-founder match plan** — in one browser conversation.

**Live:** https://ochieng7d-max.github.io/company-maker/

## Features

- Guided chat-style intake (company kind, stage, strengths, gaps, optional raise stance)
- Generated Company Brief + multi-phase roadmap with this-week actions
- Co-founder matching: ideal profiles, example archetypes, outreach script
- Pure static HTML/CSS/JS — no login, no backend, no build step

Raise goals and financial/commission rails are **conceptual only** and are not implemented.

## Local

Open `index.html` in a browser, or:

```bash
npx serve .
```

## Deploy

GitHub Pages serves from the `main` branch root.
